# NuKlean Mobile Application

Flutter mobile client app for the NuKlean B2C ordering and delivery platform.

## 🚀 Running the App
1. Copy `.env.example` to `.env` and fill in the values.
2. Run the application:
   ```bash
   flutter run
   ```

## ⚠️ SECURITY WARNING & KEY ROTATION
> [!IMPORTANT]
> **Key Rotation Warning:**
> If any environment keys, API tokens, keystore credentials, or server endpoints were previously hardcoded in configuration files or code files:
> * **Rotate all credentials immediately.** 
> * Do not reuse any credentials committed in Git history.
